### Documentation corrections (found by the sweep, `specs/postman-endpoints.md`)

- `POST /checkout` returns the **OrderGroup row**: the id is `id`, not `orderGroupId`.
- Real error codes: `INVALID_ORDER_TRANSITION` (not `INVALID_TRANSITION`), `ORDER_NOT_SHIPPED` on confirm-delivery, `BAZAAR_NOT_ACCEPTING_APPLICATIONS` (400) when applying to a non-PUBLISHED bazaar, `APPLICATION_EXISTS` (409) on a second application.
- Search routes return `{ hits, estimatedTotalHits, page, limit }` (corrected on 2026-09-20).
