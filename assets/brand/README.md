# Brand assets

Canonical home for Riven brand files used across apps and marketing.

## Expected contents

```
brand/
├── logo/
│   ├── riven-logo.svg          # Primary vector logo
│   ├── riven-logo.png          # Full-color raster export
│   ├── riven-logo@2x.png
│   └── riven-mark.svg          # Icon-only mark (favicon, app icon base)
├── colors/
│   └── brand-palette.md        # Hex values, usage notes
└── typography/
    └── brand-type.md           # Font families, weights, fallbacks
```

Add logo SVG/PNG exports and the brand board reference here when available. Do not store large unoptimized marketing renders in git — link to external storage if needed.
